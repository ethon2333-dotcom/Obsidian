# AI 模型类型与架构

> 人工智能从「单模态文本处理」向「全感知通用智能」演进的四个阶段与视角：**LLM → VLM → MLLM → LMM**。
> 以及支撑它们的两条技术路线：**外挂适配式（Adapter-based）** 与 **原生多模态（Native / End-to-End）**。

## 一句话脉络
- **LLM** 是内核：绝大多数 MLLM / LMM 的推理能力源自 LLM 范式。
- **VLM** 是分支：专注「视觉 + 文本」；当它的语言部分换成深度 LLM，就升级为 **MLLM**。
- **LMM** 是趋势：从「给 LLM 拼装眼睛（外挂 MLLM）」走向「出生就有视觉听觉（原生 LMM）」。
- 架构差异直接决定**响应速度、信息无损度、交互自然度**。

## 与「手机 AI 智能体」专题的关系
本专题是底层模型基础，手机 AI 专题是其落地场景：
- 端侧 VLM（Qwen2-VL、MiniCPM-V）正是 [[工业级 GUI Agent 架构（VLM+无障碍树）]] 的「肌肉」
