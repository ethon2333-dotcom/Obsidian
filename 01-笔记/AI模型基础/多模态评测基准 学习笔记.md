# 多模态评测基准 学习笔记

> 心智模型：**评测基准是"多模态模型能力"的尺子**——它定义了"看懂图文/图表/科学/视频/世界"到底指什么，并用一套固定考题把不同 VLM/MLLM 拉到同一条起跑线上比高低。本文是从「模型是什么」（见 [[大模型四类型：LLM VLM MLLM LMM]]、[[外挂适配式 vs 原生多模态架构]]）向外辐射的一跳：**聚焦多模态模型能力基准本身，而非 Agent 任务轨迹评测**（后者见 [[Agent 评测与基准 学习笔记]]，两者互补、边界在文末标注）。

## 广度覆盖

### 1. 定义
多模态评测基准（Multimodal Benchmark）是一组带标准答案/评分协议的多模态样本（图文、图表、视频等），用于横向衡量视觉-语言模型（VLM / MLLM）的感知、知识与推理能力。核心价值：可复现、可对比、抗"自说自话"。

### 2. 按能力维度分类
- **图文理解**：通用视觉问答、属性/场景/常识推理 → MMBench、MME、MMVet
- **图表/文档**：图表、表格、文档、OCR → AI2D、OCRBench、ChartQA 类
- **科学**：科学图表、学科知识推理 → AI2D、MMMU
- **专家级跨学科**：大学级、需领域知识+深思熟虑推理 → MMMU、MMMU-Pro
- **视频 / 世界模型**：视频时序、因果、反事实、未来预测 → MMWorld、Video-MME、LongVideoBench（长视频）
- **Agent 视觉**：视觉定位/UI grounding（与 Agent 评测交叉，本文点到为止）——见 [[端侧多模态 VLM 学习笔记]]、[[多模态 GUI 理解与 UI Grounding 学习笔记]]

### 3. 主流基准清单

| 基准 | 机构 | 覆盖能力 | 年份 |
|---|---|---|---|
| MMBench | 上海 AI Lab（NTU 等合作） | 全能多维度（感知+推理，20+ 维），中英双语，CircularEval | 2023 |
| SEED-Bench | Tencent AI Lab | 图文+视频理解，12 维，19K 多选题 | 2023 |
| MMVet | Microsoft | 集成能力：6 大核心 VL 能力 → 16 种任务组合 | 2023 |
| MME | Tencent AI Lab / 厦大（待核实） | 感知+认知 14 子任务 | 2023 |
| MMMU | OSU / CMU / Waterloo 等 | 大学级跨学科专家推理，6 学科 30 学科，11.5K 题 | 2023（CVPR 2024） |
| AI2D | Allen AI (AI2) + UWashington | 科学图表理解（三层推理架构） | 2018 起，常用基准 |
| OCRBench | 武汉大学 / Tencent（机构待核实） | OCR 与视觉文本，v2 覆盖 31 场景 10K+ QA | 2023（v2 2024） |
| MMStar | USTC / Tencent（机构待核实） | 视觉依赖性（反作弊过滤纯文本可答题），~1,500 题 | 2024 |
| MMMU-Pro | OSU / CMU / Waterloo 等 | MMMU 加固版：10 选项 + 视觉仅输入，~3,460 题，随机基线 10% | 2024（ACL 2025） |
| MMWorld | UCSC / UCSB / Microsoft | 视频"世界模型"：多学科 + 多维度推理，1,910 视频 6,627 QA | 2024 |
| Video-MME | Tencent AI Lab | 综合视频理解（首批综合视频基准） | 2024 |
| MME-RealWorld | 机构待核实 | 高分辨率真实场景，最大规模人工标注 | 2024 |

### 4. 2025–2026 进展（点到为止）
- **MMMU**：测试集答案于 2026-02 放出，可在本地评测（此前只有验证集公开）。
- **MMMU-Pro** 被 ACL 2025 接收，成为更鲁棒的专家级评测标准（过滤纯文本可答题 + 10 选项 + 视觉仅输入）。
- **新基准涌现**：2025–2026 出现 VMCBench、MMVU、MMT、MMBench 长视频/多语言扩展、MME-RealWorld-lite 等（具体规模与 SOTA 待核实，见文末）。
- **评测框架成熟**：OpenCompass + VLMEvalKit 成主流开源统一评测平台；LMArena 多模态 Arena 提供众包 pairwise 对战榜。
- **趋势拐点**：从"图像问答"转向"视频 / 长视频 / 世界模型 / agent 视觉"，并普遍强调**抗作弊**与**视觉依赖性**（MMStar、MMMU-Pro 为代表）。

### 5. 代表榜单 / 产品

| 榜单 / 平台 | 维护方 | 特点 |
|---|---|---|
| OpenCompass / VLMEvalKit | 上海 AI Lab | 开源统一多模态评测框架，覆盖数百模型 |
| LMArena（Multimodal） | LMArena 团队 | 众包 pairwise 对战榜，偏"人类偏好" |
| MMMU Leaderboard | 官方 EvalAI | 专家级多学科排名 |
| MMBench Leaderboard | 官方 | 全能维度排名 |
| MMWorld @ AGI-Eval | AGI-Eval 社区 | 视频世界模型评测托管 |
| MME-RealWorld | 官方 | 高分辨率真实场景 |

> ⚠️ 具体模型的 SOTA 分数变动极快，本文**不写死任何榜单数字**；落地查分时以上述官方/平台实时榜单为准。
