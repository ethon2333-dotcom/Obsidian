# 交互说明四问法（全课核心）

> [!abstract] 一句话
> 每条功能点 = **触发 + 动作 + 反馈 + 异常**。写满这 4 问，研发拿到不用追问就能开发。
> 回到 [[PRD MOC]] ｜ 配套 [[PRD_Template]] 第六章

## 四问
1. **触发**：用户在什么页面、什么状态下操作？
   - 例：未登录用户在登录页点击「获取验证码」
2. **动作**：做了什么？
   - 例：输入手机号 + 点击按钮
3. **反馈**：系统正常时怎样？
   - 例：校验通过 → 按钮进入 60s 倒计时；成功 → 跳转首页
4. **异常**：失败 / 边界怎样？
   - 例：手机号非法 → Toast「请输入正确的手机号码」；断网 → 「网络连接不稳定」；重复点 → 按钮 Disabled 防抖

## 可复用小模板（粘到每个功能模块下）
```markdown
#### [功能名] 交互说明
- 触发：<页面 + 状态 + 操作>
- 输入/前置：<字段、权限、数据>
- 正常流程：<步骤1 → 步骤2 → 结果>
- 校验规则：<格式、范围、频率限制>
- 异常/边界：<失败提示、超时、空数据、重复提交、极值>
- 埋点：<对应模板 7.4 事件名>
```

## 实例：手机验证码登录（对应模板 6.1）
- **触发**：未登录用户在登录页，手机号输入框已输入 11 位手机号，点击「获取验证码」
- **动作**：客户端提交手机号 → 调发送验证码接口
- **反馈**：成功 → 按钮置灰进入 60s 倒计时，Toast「验证码已发送」；用户输完 6 位 → 校验通过 → 跳转首页
- **异常**：
  - 手机号非法 → Toast「请输入正确的手机号码」
  - 60 秒内重复点 → 按钮 Disabled，不重复发请求
  - 断网 → Toast「网络连接不稳定，请检查网络」
  - 单日超 10 次 → Toast「今日发送次数已达上限」
  - 接口超时（>5s）→ 提示「网络连接超时，请重试」

> 看课程第 12–15 集演示，对照上面实例检查自己漏了哪类「异常」，再用 [[PRD-写完自检清单]] 自检。
