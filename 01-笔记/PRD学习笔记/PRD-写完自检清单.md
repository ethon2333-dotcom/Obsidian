# PRD 写完自检清单

> 写完 PRD 后逐条过 ｜ 回 [[PRD MOC]] ｜ 核心写法见 [[PRD-交互说明四问法]]

- [ ] 每个 P0 功能都有「触发 / 动作 / 反馈 / 异常」四要素？（四问法）
- [ ] 校验规则与边界覆盖模板 6.1.2 / 6.1.3 列举项？
- [ ] 流程图（第四章）与第六章功能一一对应？
- [ ] 非功能需求（七）给了可量化指标（如 ≤200ms、QPS≥1000）？
- [ ] 埋点（7.4）与交互步骤对得上？
- [ ] 研发拿到不用再追问就能开发？
- [ ] 修订日志（1.1）从 V1.0.0 起已建，相关文档链接（1.3）已补？

> [!note] 课程没覆盖的部分也要补
> 二（背景/KPI）、三（用户/场景）、七（非功能）、八（上线灰度）本套课不讲，但正式 PRD 缺一不可——参考 [[PRD-模板章节与课程对照]]。
