# 功能点拆解（模板第五章）

> 对应课程第 4 集 ｜ 回 [[PRD MOC]] ｜ 模板见 [[PRD_Template]] 第五章

## 作用
功能清单是 PRD 的「目录」：在写详细交互（第六章）之前，先让所有人对齐**要做哪些功能、优先级、覆盖哪些端**。

## 拆解维度
- **模块**：如「账号体系」「风控安全」
- **功能点**：模块下的具体能力
- **优先级**：P0（必须有）/ P1（重要）/ P2（锦上添花）
- **适用终端**：iOS / Android / Web / 全平台
- **备注**：兜底、依赖、特殊说明

## 模板示例
| 模块 | 功能点 | 描述 | 优先级 | 终端 |
| :--- | :--- | :--- | :--- | :--- |
| 账号体系 | 手机号一键登录 | 运营商 SDK 拉取手机号 | P0 | iOS/Android |
| 账号体系 | 短信验证码登录 | 兜底方案 | P0 | 全平台 |
| 风控安全 | 人机图形验证码 | 异常频繁时触发 | P1 | 全平台 |
