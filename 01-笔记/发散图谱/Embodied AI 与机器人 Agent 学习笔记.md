> **心智模型一句话**：Embodied AI = 把 LLM 的"脑子"装进"身体"，让「感知 → 决策 → 执行」的闭环跑在真实物理世界里，而不只是屏幕上生成文字。

---

## 1. 定义与分类

| 维度 | 说明 |
|---|---|
| **Embodied AI 是什么** | 具备物理/虚拟身体、能感知环境、自主决策并施加动作以改变世界的智能体；核心是「具身闭环」而非纯推理。 |
| **vs 纯软件 Agent** | 纯软件 Agent 在信息空间行动（调 API、改文件）；具身 Agent 在物理空间行动（抓取、移动），受动力学/因果约束。 |
| **vs GUI Agent** | GUI Agent 操作屏幕像素与控件（见 [[工业级 GUI Agent 架构（VLM+无障碍树）]]）；具身 Agent 操作真实物体，模态从像素扩展到力/触觉/深度。 |
| **vs 自动驾驶** | 自动驾驶是「具身智能的单任务特例」——只有轮式移动+感知，无通用操作；具身 AI 强调跨任务、跨本体的通用策略。 |
| **机器人形态谱系** | 人形（Figure/Optimus/Unitree G1）· 轮式（Agility Digit/配送机器人）· 机械臂（Franka/协作臂）· 通用操作（移动操作复合本体）· 四足/特种。 |

## 2. 技术栈（感知 → 动作）

| 层级 | 关键点 | 代表 |
|---|---|---|
| **Perception 多模态感知** | 视觉+深度+触觉+力觉+IMU，融合成世界状态表征 | 立体视觉、3D LiDAR、指尖力/触觉传感器、RGB-D |
| **VLA 模型**（Vision-Language-Action） | 把视觉/语言指令直接映射为连续动作，2025 起成主流范式 | Google Gemini Robotics、NVIDIA GR00T、Figure Helix、Physical Intelligence π 系列、OpenVLA |
| **World Model / 仿真** | 用视频/物理引擎预测未来状态，生成训练数据、降低真机依赖 | NVIDIA Isaac Sim、RynnVLA-002（VLA+World Model 统一）、GigaBrain-0、UniVLA |
| **Sim-to-Real** | 仿真数据 → 真机策略迁移，缓解真机数据采集昂贵瓶颈 | Isaac GR00T 训练栈、域随机化、世界模型生成数据 |
| **端侧部署** | 量化(VLA)+边缘算力，本体本地低延迟推理、断网可用 | Gemini Robotics On-Device、NVIDIA Jetson Thor、Jetson Orin 上跑轻量 VLA |

> 关键趋势：竞争重心从「本体硬件参数」转向「模型/大脑能力」——多份资料称机器人"大脑"层是更持久的护城河（类比 Physical AI 时代的 Android/iOS）。

## 3. 2025–2026 进展（点到为止）

- **VLA 成主流**：2025 年发布的 Helix、GR00T N1、Gemini Robotics、π0/π0.5 将 VLA 从论文推向量产路线；有行业报告称 2026 Q1 已有 ≥11 个商业部署以 VLA 为主干（**该数字为单一行业调查口径，待核实**）。
- **世界模型/仿真训练**：VLA+World Model 统一框架涌现（RynnVLA-002 在 LIBERO 仿真达 97.4% 成功率；真机 LeRobot 实验世界模型提升整体成功率约 50%——**均为论文口径，非产品指标**）。
- **端侧推理上机器人**：Gemini Robotics On-Device（2025-06）支持本体本地运行、50–100 次示范即可微调；Jetson Thor 等边缘芯片使量化 VLA 以单瓦级功耗跑 10–25 Hz（**来源为行业博客，待核实**）。
- **资本与厂商**：2025 年机器人/Physical AI 初创融资约 $27.6B（同比约 2×，来源 PitchBook 口径，待核实）；Physical Intelligence 估值约 $5.6B（2025-11 Series B，待核实）。中国厂商（Unitree/智元 AgiBot）以低价+量产策略领先出货规模。
- **诚实边界**：当前落地以工厂/仓库/受监督窄任务为主；**无监督家庭通用助手"仍未到来"**（多来源一致结论）。

## 5. 与端侧智能 / 意图框架的同源关系

具身智能不是孤立范式，它与本库已覆盖的「端侧 AI / 多模态感知 / 意图框架」**共用同一套技术基因**：

- **多模态感知同源**：机器人视觉/深度/触觉栈，与 [[AI 眼镜与可穿戴意图入口 学习笔记]] 的摄像头+IMU 感知、[[智能座舱与车机 HMI 意图入口 学习笔记]] 的车外视觉/舱内感知，本质都是「把世界编码成模型能懂的表征」。
- **端侧推理同源**：Gemini Robotics On-Device、Jetson 系列证明"大模型可在设备本地跑"——这与手机端侧 Agent 的 NPU/量化部署是完全同构的问题（延迟、功耗、断网可用）。
- **意图理解同源**：VLA 的「语言指令 → 动作」与 GUI Agent 的「自然语言意图 → 屏幕操作」（见 [[无障碍 Accessibility 与 GUI Agent 同源技术栈 学习笔记]]）都是"意图到执行"的映射学习，只是执行器从像素控件变成真实关节。
- **跨端流转同源**：当机器人、眼镜、车机、手机都跑同一类多模态意图模型，[[跨端与多设备意图流转]] 的"一个意图跨端接续"将从屏幕扩展到物理世界。

> 一句话：具身智能是「端侧多模态意图框架」在物理世界的终极外溢形态。

## 6. 对 OS PM 的意义（安卓系统视角）

- **意图入口的物理化**：未来"系统入口"未必是 App 或语音助手，而可能是具身 Agent 接管现实任务（取物、递送、操作设备）——OS 需思考如何成为「物理意图」的调度层。
- **端侧算力需求上探**：VLA/World Model 的端侧推理对 NPU 带宽、内存、能效提出远超当前手机 LLM 的需求；PM 应提前规划"机器人/穿戴/车机"统一的端侧推理底座。
- **跨端流转成刚需**：当意图可在手机→眼镜→车机→机器人间无缝接续，OS 层的「意图总线 / 设备能力发现」将成为新的平台级护城河。
- **安全与权限模型**：物理执行（动别人的东西）比屏幕操作风险更高，需要更严格的「动作权限 / 确认机制 / 可撤销」设计。
- **长期启示**：具身智能可能重演"App → Agent"的范式迁移——PM 应把「通用策略模型」视为继内核、运行时之后的新系统核心能力。
