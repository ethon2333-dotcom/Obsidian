## 发散分支（本图谱新建）
- [[端侧 AI 基建与算力预算]] —— NPU / 量化 / 端侧 Runtime / 内存显存预算，决定端侧 Agent 能不能跑、跑多快
- [[意图框架的商业与生态博弈]] —— 超级 App 阻力、流量入口、利益共享、联盟标准，安卓落地的最大变量
- [[跨端与多设备意图流转]] —— 手机作意图中枢，向车机 / IoT / PC 流转
- [[Agent 记忆与个性化意图理解]] —— 用户记忆 + 端侧 RAG，让同一句话对不同人意图不同
- [[AI 眼镜与可穿戴意图入口 学习笔记]] —— **形态外辐射**：无屏/小屏形态下 GUI Agent 范式失效，语音+视觉成主入口；玩家谱系与功耗约束
- [[智能座舱与车机 HMI 意图入口 学习笔记]] —— **跨端外辐射**：车机作为意图入口的形态谱系与玩家横向（鸿蒙座舱/小米/蔚小理/百度/高通/英伟达/AAOS），与手机端侧意图框架的同源技术
- [[无障碍 Accessibility 与 GUI Agent 同源技术栈 学习笔记]] —— **同源技术外辐射**：屏幕阅读器 / 无障碍树这套为视障服务的技术，正是 GUI Agent「看懂界面」的同源底座，与 [[工业级 GUI Agent 架构（VLM+无障碍树）]] 直接呼应
- [[Embodied AI 与机器人 Agent 学习笔记]] —— **形态谱系终点站**：从眼镜、车机继续外辐射到具身/机器人入口。机器人 Agent 范式（VLA / 机器人基础模型 / 世界模型驱动 sim-to-real）与手机端侧意图框架是「同一个感知→决策→执行闭环的两种身体」；因动作不可撤销，「先想后做 + 显式成功检测 + 端侧实时兜底」在这里被提前逼出答案
- [[AI 视频与多模态生成 学习笔记]] —— **热点新知外辐射**：生成式多模态（文生视频/图/音频）产品格局与技术范式（扩散+时空一致性 / 自回归 / 世界模型驱动）。与 [[端侧多模态 VLM 学习笔记]]（端侧理解，非生成）、[[世界模型与仿真合成环境 学习笔记]]（上游技术）区分；聚焦 Sora 2 / Veo 3 / 可灵 / Runway / Pika / Midjourney / FLUX / Suno 玩家格局与端侧生成差距留白
