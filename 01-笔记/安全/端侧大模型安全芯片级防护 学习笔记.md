心智模型：把模型权重和推理过程锁进硬件信任根，让"有 root 权限的用户也读不到明文权重"——这是软件层越狱防护（[[端侧模型安全与越狱 学习笔记]]）兜不住的那一层。

## 一、概念定义（点到为止）

| 概念 | 一句话 | 与端侧 LLM 的关系 |
|---|---|---|
| 硬件信任根 RoT | 固化在硅片、不可篡改的密钥/代码（如 Apple UID/GID、Qualcomm eFuse） | 一切密钥派生与证明的锚点 |
| TEE 可信执行环境 | 主处理器内隔离安全区，OS/Hypervisor 也看不到内部代码数据 | 权重加密存储 + 运行时解密推理 |
| SE / iSE 安全元件 | 独立或集成的安全芯片（smart-card 级） | 主要锚定密钥、安全启动链、iSIM |
| Secure Enclave | Apple 的 TEE 实现：独立协处理器 + 加密内存 + 真随机数 | 生物识别/小模型隔离 |
| NPU 安全域 | 在 NPU 上以安全模式跑推理 | 加速密态推理、防内存泄露 |

## 二、分类：TEE vs SE vs Secure Enclave vs NPU 安全域

| 维度 | TEE（TrustZone/TDX） | SE / iSE | Secure Enclave | NPU 安全域 |
|---|---|---|---|---|
| 形态 | 主芯片内隔离区 | 独立/集成安全芯片 | Apple 协处理器 | NPU 安全模式 |
| 防护对象 | 代码+数据+内存 | 密钥为主 | 生物识别+密钥+小模型 | 推理计算 |
| 可编程性 | 高（可跑自定义模型） | 低（固化 applet） | 中（Apple 受限） | 取决于实现 |
| 端侧 LLM 用途 | 权重加密存储+运行时解密 | 密钥锚定 | 小模型/生物识别 | 加速密态推理 |
| 代表 | ARM TrustZone、Intel TDX | Qualcomm SPU、SIM | Apple | Secure Neural Engine、TZ-LLM |

## 三、主流方案横向对比（厂商与芯片平台）

| 厂商/平台 | 硬件机制 | 端侧模型保护点 | 状态/进展 | 备注 |
|---|---|---|---|---|
| Apple（A11+/M1+） | Secure Enclave + Secure Neural Engine + UID/GID | 小模型/生物识别隔离、专用加密内存 | 量产（A14/M1 后 NE 以安全模式实现） | 不可任意加载模型（受限 TEE） |
| ARM（v8/v9） | TrustZone + CCA/RME Realm | TEE 隔离推理 + Realm 机密域 | TF-M、CCA 持续演进；TZ-LLM 2025 落地 | Realm 为 VM 级隔离，适配大模型内存 |
| Qualcomm（Snapdragon） | Secure Processing Unit（on-die iSE 类）+ Secure Boot/eFuse | 密钥锚定、安全启动链、iSIM | SPU 2019 即获 EAL-4+ | "iSE" 命名/2025-2026 具体能力待核实 |
| Intel（Xeon） | SGX / TDX | 边缘/云端机密 LLM 推理（VM 级 TD） | IISWC 2025 实测 TDX 吞吐损耗 <10% | 主要服务器/边缘，端侧 PC 亦可用 |
| NVIDIA（Hopper/Blackwell） | Confidential GPU（H100 cGPU）+ IDE 加密通道 | GPU 侧密态推理、HBM 加密 | IISWC 2025 实测吞吐损耗 4-8% | 端侧 GPU 覆盖待核实，当前集中于服务器级 |
| 学术原型 | DarkneTZ / StrongBox / Soter / GuaranTEE / TZ-LLM | TEE 内权重 + 流水线解密 | 2022-2026 多篇 | 研究为主，未大规模商用 |

## 四、2025-2026 进展

| 进展 | 来源 | 关键信息 |
|---|---|---|
| TZ-LLM | arXiv 2511.13717（2025-11） | Arm TrustZone 保护端侧 LLM；pipelined restoration + NPU co-driver；TTFT 降最多 90.9%、解码 +23.2%；OpenHarmony + Rockchip 3588 实测（TinyLlama-1.1B~Llama-3-8B） |
| Confidential LLM Inference | IISWC 2025（arXiv 2509.18886） | 基准 Intel TDX/SGX 与 NVIDIA H100 cGPU；CPU TEE 全内存加密更安全，GPU TEE 当前 HBM/NVLink 未加密 |
| ArrowCloak / ArrowMatch | USENIX Security 2025 | 揭示 TEE-shielded 拆分推理"权重方向泄露"；后续 ArrowRevelio 利用结构恢复 ~100% 权重——轻量混淆 ≠ 安全 |
| ARM CCA / RME Realms | ARM 官方 | 从 TrustZone（安全区）扩展到 Realm（机密域 VM 级），缓解大模型内存规模问题 |
| 侧信道攻击线 | DeepSteal（RowHammer）/ HyperTheft·CipherSteal（GPU 总线）/ Hermes（PCIe 流量） | TEE 之外的物理泄露面，需与软件混淆叠加防护 |

## 五、代表产品与研究（速览）

- **Apple Platform Security**：Secure Enclave 用 UID/GID 将加密数据绑定设备；A14/M1 起 Secure Neural Engine 以安全模式实现。
- **Qualcomm SPU**：首个获 smart-card 等效 EAL-4+ 的移动 SoC（Snapdragon 855，2019），on-die 取代外置安全芯片。
- **Intel TDX**：整机 VM 级隔离，对 hypervisor/云管不可见，适配"lift-and-shift"机密 LLM。
- **NVIDIA H100 Confidential GPU**：GPU 内硬件信任根 + HBM 加密 + PCIe IDE 加密通道。
- **TZ-LLM / DarkneTZ / StrongBox（首个 GPU TEE）/ Soter / GuaranTEE**：TEE 内权重与拆分推理的研究体系。
