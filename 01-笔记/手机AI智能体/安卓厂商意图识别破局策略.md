# 安卓厂商意图识别破局策略

> 安卓厂商破局，不能把赌注全押在「逼超级 App 开放 API」，也不能指望脆弱的「屏幕模拟点击（GUI Agent）」支撑商业体验。
> 核心：**技术上做双轨并行与降级保障，商业上做利益共享与流量诱导，生态上做统一联盟。**

## 一、技术破局：构建「三层梯队」执行架构

厂商不能等 App 完美适配，要建立渐进式退让（Progressive Fallback）执行引擎：

```
                 系统级 AI 意图解析引擎
                            │
         ┌──────────────────┼──────────────────────────┐
         ▼                  ▼                          ▼
┌─────────────────┐  ┌─────────────────┐       ┌─────────────────┐
│  L1: 原生 API   │  │ L2: 深层协议     │       │ L3: 工业级      │
│  (Intent Schema)│─失败→│ (DeepLink/Schema)│─失败→│ GUI Agent       │
└─────────────────┘  └─────────────────┘       └─────────────────┘
 高稳定性/低延迟       中稳定性/免打开            底线保障/视觉操控
```

- **L1（原生 Intent 合作）**：对愿深度合作的 App / 中小优质 App，走标准原生 API。
- **L2（深层协议与系统服务利用）**：利用现有 Deep Link、URL Scheme、系统剪贴板、Notification 监听。许多 App 虽没开放 Intent，但暴露大量页面跳转 Scheme（如 `app://restaurant/detail?id=123`），AI 可直接拼装 URL 无缝直达。
- **L3（工业级 GUI Agent）**：终极保底，兜底未适配且无协议暴露的 App。

## 二、体验破局：把 GUI Agent 从「玩具」做成「工业级」

厂商有操作系统底层最高权限（第三方软件没有）：
- **视觉 VLM + 源码 DOM 树多模态融合**：第三方 Agent 只能看截图，安卓厂商可直接读系统 Accessibility Node Info（无障碍节点树），结合端侧轻量 VLM 提升识别率。
- **Set-of-Marks（SoM）与语义控件映射**：不让 AI 记固定坐标（分辨率 / 改版会变），而是让端侧模型实时把屏幕元素标记为语义对象（如「【提交订单】按钮」），即使换 UI 皮肤或改位置也能基于语义精准点击。
- **云端自愈与轨迹共享（Self-Healing）**：某版本微信 / 美团更新界面导致识别失败，只要一个用户经云端 LLM 校正生成新「点击路径」，即可秒级下发复用给全网同型号手机，实现集体进化。

## 三、商业破局：重构利益链，「不吃独食」

超级 App 抵抗 Intent 的根本原因是怕被「管道化」和「切断广告 / 支付转化」。破局必须给大厂留空间：
- **只做「导流」与「前置发起」，不做「闭环拦截」**：涉及下单、付款、选座、确认等核心节点，AI 自动填好所有参数并跳转 App 原生界面，让用户在 App 内完成最后一次点击确认（如指纹支付）。这样 App 保住 DAU、GMV、支付链、转化归因，消除戒心。
- **流量虹吸与「逆向逼迫」**：把负一屏、系统全局搜索、桌面卡片等核心入口优先倾斜给主动适配 Intent Schema 的 App。例如携程适配后，搜机票直接展示极速打折卡片一键下单；未适配的只能普通图标呈现。用流量重分配倒逼竞争对手跟进。

## 四、生态破局：推动「厂商联合意图联盟」

开发者最头疼「小米一套、OPPO 一套、vivo 又一套」。安卓厂商需重走「统一推送联盟 / 快应用」路线，在信通院或行业协会牵头下，联合制定统一 Android Intent Schema 行业标准。开发者写一套意图声明文件即可被所有主流厂商识别，适配成本降 80%+，是生态爆发前提。

## 五、感知破局：系统级「暗度陈仓」

意图识别不该只发生在「长按电源键唤醒语音助手」时，应利用系统权限前置：

```
               系统级多模态前置感知 (Pre-Intent)
  ┌──────────────────┬──────────────────┬─────────────────────┐
  │  剪贴板/输入法   │  屏幕实时 OCR    │   系统通知栏        │
  │ (复制快递单号)   │ (看小红书酒店)   │ (收到航班延误短信)  │
  └────────┬─────────┴────────┬─────────┴──────────┬──────────┘
           └──────────────────┼────────────────────┘
                              ▼
                 主动生成「下一步动作」预推卡片
```

- **输入法与剪贴板感知**：复制淘口令 / 酒店地址，键盘上方主动弹「一键转存备忘录」「一键打车」。
- **屏幕上下文（On-Screen Context）**：看小红书攻略时唤醒 AI，AI 已知当前屏幕景点名，用户只需说「帮我查门票」。

## 本质
安卓厂商破局不是靠技术打败超级 App，而是用工业级 GUI Agent 打底确保体验可用，再用系统流量与利益共享拉拢 App 厂商，最终促成 Intent 生态妥协与共建。
