# 端侧扩散模型与端侧图像生成 学习笔记

> **心智模型一句话**：端侧文生图 = 把本来要几十步、跑在云 GPU 上的扩散流程，用「结构瘦身 + 步数蒸馏 + NPU 专用加速」三板斧塞进手机，换来了**隐私不出端、零云端成本、离线可用**，代价是分辨率/质量暂时打不过云端旗舰模型。

本文是「手机 AI 智能体 / 端侧」锚点向外辐射的一跳，**聚焦生成侧**（文生图），与已覆盖的 [[端侧多模态 VLM 学习笔记]]（视觉**理解**）形成对照：一个让手机「看懂」，一个让手机「画出来」。

---

## 1. 定义与边界

- **端侧扩散（on-device diffusion）**：在手机 SoC（NPU / GPU / CPU）本地跑 Stable Diffusion 类扩散模型的文生图 / 图生图 / 局部重绘，数据不出设备。
- **核心瓶颈**：标准 SD 推理 = 文本编码器（跑 1 次）+ UNet 去噪（迭代 20–50 次，绝对主力）+ VAE 解码。手机端慢在「UNet 反复算」+「VAE 解码」+「内存带宽」。
- **加速三板斧**（广度点到为止，细节留给 Ethon）：
  1. **架构瘦身**：重设计 UNet / 改用 DiT-lite、共享投影、可分离卷积、剪枝 VAE。
  2. **步数蒸馏**：CFG-aware 蒸馏、一致性模型（LCM）、Diffusion-GAN 混合，把 50 步压到 1–8 步。
  3. **硬件加速**：NPU 专用量化（W8A16 等）+ 编译栈（QNN / Core ML / MNN）。

## 2. 分类（按加速路线）

| 类别 | 思路 | 代表 |
|---|---|---|
| 高效架构 + 步数蒸馏 | 改 UNet + CFG 蒸馏 | SnapFusion |
| 一步/少步生成 | Diffusion-GAN、对抗微调 | MobileDiffusion、SDXL Turbo / SD Turbo |
| 一致性模型 | 解 PF-ODE，直接预测潜空间解 | LCM（Latent Consistency Models）、原版 Consistency Models |
| 端侧运行时/产品 | 把上述模型搬上手机 NPU | Apple Image Playground、Draw Things、Local Dream |

## 3. 主流方案（研究侧，表格）

| 方案 | 出处/厂商 | 端侧落地形态 | 备注 |
|---|---|---|---|
| SnapFusion | Snap Research + 东北大学（NeurIPS 2023） | iPhone 14 Pro | < 2s 出 512px 图；8 步去噪；FID/CLIP 优于 SD v1.5（50 步）；高效 UNet + CFG-aware 蒸馏 |
| MobileDiffusion | 研究（2024） | iPhone 15 Pro | < 0.2s 出 512px；一步采样（Diffusion-GAN 混合）；支持 LoRA / ControlNet 类下游 |
| LCM（Latent Consistency Models） | 清华 Luo et al.（arXiv 2310.04378, 2023） | 可蒸馏进 SD1.5 / SDXL | 从预训练 SD 蒸馏仅需 ~4000 步（~32 A100 GPU 时）；768×768 在 2–4 步甚至 1 步出图；含 LCM-LoRA |
| Google 移动端推理优化 | 研究（Efficient Diffusion Survey 收录） | S23 Ultra / iPhone 14 Pro Max | Winograd 卷积 + FlashAttention，延迟降 52.2% / 32.9%，20 步 < 12s，内存≤2.1GB |
| Bonsai Image（1-bit DiT） | PrismML（2025 实验） | Galaxy S25+ 骁龙 8 Elite Hexagon NPU | 512×512 全渲染约 2 分钟+；混合精度偏软；仍偏实验，未成品 App |

## 4. 2025–2026 进展（广度）

- **芯片侧**：骁龙 8 Elite 的 Hexagon NPU 成为安卓端侧 SD 的主流落点；联发科天玑旗舰 NPU 也能跑，但**具体量产产品/数字待核实**。
- **产品侧（消费级）成熟**：Apple 把端侧扩散做成系统级服务（Image Playground / Genmoji / Image Wand）；iOS 第三方（Draw Things）做到离线、可训练 LoRA；安卓出现开源旗舰（Local Dream，2025-01 起，骁龙 NPU 加速）。
- **加速范式收敛**：「蒸馏到少步 + NPU 量化」成事实标准；LCM / LCM-LoRA 生态进入 Diffusers 主线，SD1.5/SDXL/SSD-1B 均可取。
- **未定趋势（留给 Ethon 跟踪）**：DiT 架构（如 SD3 / Flux 类）能否上手机 NPU、1-bit/低比特扩散在终端的实用性、视频生成何时能端侧实时。

## 5. 代表产品（表格）

| 产品 | 平台/厂商 | 形态 | 备注 |
|---|---|---|---|
| Apple Image Playground / Genmoji / Image Wand | iOS/iPadOS/macOS（Apple Intelligence） | 系统级、纯端侧（ANE/Apple Silicon） | 动画/插画/素描三风格；iPhone 15 Pro 起；速度秒级；质量偏卡通非写实 |
| Draw Things | iOS / iPad / macOS | App，离线本地跑模型 | 支持 txt2img、img2img→video、无限画布、本地训练 LoRA；完全免费离线 |
| Local Dream | Android（开源，xororz） | App，骁龙 Hexagon NPU 加速 | QNN SDK + W8A16；MNN 兜底 CPU/GPU；txt2img/img2img/inpaint；可导入 SD1.5 模型与 LoRA |
| Core ML Stable Diffusion / stable-diffusion.cpp | 开源生态 | 推理运行时 | 苹果官方 Core ML 转换；cpp 版可在 CPU 跑（含 1-bit 实验分支） |

## ⚠️ 待核实清单

- **骁龙 8 Elite「80 TOPS」**：来自厂商/媒体稿，为 AI 引擎整体口径，非端侧扩散专项实测，待查高通官方白皮书确认精确场景与单位。
- **LCM-Light「iPhone 15 上 2 秒生成 512×512」**：出自多个中文 CSDN/51CTO 营销向文章，口径雷同、来源弱，未见于 LCM 原论文或 HuggingFace 官方卡；**待核实**是否为实测还是转述。
- **各 CSDN 文的一致性模型 FID/成本数字（如 FID=6.20、成本降 80%、能耗降 62%）**：营销口径，原论文仅给 LCM 蒸馏训练成本（~32 A100 GPU 时），上述终端指标**待核实**。
- **联发科天玑端侧文生图的具体量产产品与性能数字**：本轮检索未获得权威一手来源，**待核实**。
- **SnapFusion / MobileDiffusion 的「<2s / <0.2s」**：来自论文与综述报道，为特定设备（iPhone 14 Pro / 15 Pro）实测，换设备/分辨率不成立，**注意场景限定**。
- **Bonsai Image 出图约 2 分钟**：为 2025 实验性 1-bit DiT 经 NPU 扩展权重后的结果，非成熟产品体验，**待核实**后续是否有提速。
