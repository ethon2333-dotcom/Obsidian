> **一句话心智模型**：端侧（设备侧）模型微调，是用 LoRA/adapter 这类「只动极小参数」的高效方法，在手机/NPU 上把通用基座模型改造成「懂你」的个性化模型——与蒸馏（造小模型）、后训练（云端对齐）、记忆（存上下文）都不同，它的核心是「在设备上改权重」。

## 广度覆盖

| 维度 | 要点（点到为止） |
|---|---|
| **定义** | 在消费设备（手机/PC/可穿戴）上对已有基座模型做参数高效微调（PEFT）或个性化训练，使模型适配个人数据/特定任务，尽量不出端、不依赖云端大模型。 |
| **分类 · 高效微调方法谱系** | • **LoRA**（Hu et al. 2021）：冻结基座，注入低秩 A/B 矩阵，可合并回权重、零推理开销。<br>• **QLoRA**（Dettmers et al. 2023）：4-bit NF4 量化基座 + LoRA，单卡可微调 65B 级。<br>• **DoRA**（ICML 2024）：分解 magnitude/direction，单位秩质量更高。<br>• 衍生：**VeRA / rsLoRA / LoftQ / PiSSA / GaLore / LoRA+** 等。<br>• **Adapter / 前缀微调**：Apple 端侧即走 adapter 路线。 |
| **主流方案（设备/框架）** | • **Apple Foundation Models 框架**（WWDC25，iOS 26 系）：开发者可用 Python 工具包训练自定义 LoRA **adapter**（rank≈32，约 160MB，经 Background Assets 下发），随 App 在端侧加载运行。<br>• **Google AI Edge / ML Kit GenAI**（I/O 2025，Gemini Nano）：已开放端侧推理 API，微调能力（NNTrainer / 动态 adapter 层）处规划/早期阶段。<br>• **Qualcomm Snapdragon（Hexagon NPU）/ MediaTek Dimensity**：提供端侧推理与训练 SDK 生态。 |
| **2025-2026 进展** | • PEFT 已成端侧微调事实标准：内存降 10-20×，保留约 90-95% 全量微调质量（superteams/llm-stack 综述）。<br>• **联邦微调（Federated Fine-tuning）** 升温：仅聚合 adapter/LoRA，上行流量较全量 FedAvg 降 >99%（FedGen-Edge, arXiv 2511.11585, 2025-12）；隐私增强方案 **DP-FedLoRA**（arXiv 2509.09097, 2025-09）引入差分隐私。<br>• **Split Federated Learning** 把部分层/激活卸载到边缘服务器，缓解异构设备显存压力（arXiv 2506.02940, 2025-06，约降 79% 显存）。<br>• 研究警示：PEFT 仍需存中间激活，端侧训练显存约为全量微调的 >70%（待核实具体数值）。 |
| **代表产品 · 厂商** | • Apple：端侧 3B 基座 + 专用 adapter 驱动 Live Translation / Genmoji / Visual Intelligence / Fitness。<br>• Google：Gemini Nano（端侧推理）+ AI Edge / Gemma 3n（开放端侧模型）。<br>• 学术/框架：FedGen-Edge、DP-FedLoRA、S-LoRA（多 adapter 并发服务）。<br>• 个人化「personal LoRA」多仍处于研究/早期试验阶段（产品化落地面待核实）。 |

## 与库内相邻笔记的关系（差异化定位）

- 与 [[端侧大模型推理 学习笔记]]：**推理**是用现成模型跑；本笔记是**训/改**模型——前者消耗算力，后者消耗算力+数据。
- 与 [[模型蒸馏与师生训练 学习笔记]]：**蒸馏**是「大模型教小模型」造新模型；**微调**是「在已有模型上小幅改权重」，不改模型体量。
- 与 [[合成数据与模型后训练 学习笔记]]：**后训练（SFT/DPO/RLHF）** 多在云端大规模对齐；**端侧微调**聚焦设备侧、小数据、个性化的末端适配。
- 与 [[个性化与端侧用户记忆 学习笔记]]：**记忆**是存/检索上下文（不改权重）；**训练**是真正更新模型参数，是更重的个性化手段。
