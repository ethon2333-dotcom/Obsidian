# 一句话心智模型
端侧留存个性化数据带来体验连续，但也带来「如何被用户/法规删除」的硬约束；遗忘权与 machine unlearning 是端侧个性化的必经关卡。

## 广度覆盖（点到为止）

### 定义
- **本地留存（retention）**：端侧为保持个性化体验连续性，把使用模式、适配权重（LoRA adapter / 记忆）、联邦 checkpoints 等保存在设备。
- **删除/撤回（erasure / withdrawal）**：用户或法规触发时移除其个人数据；区别于「联邦边界」篇讲的「数据不出端」的传输约束，本篇聚焦「存下来之后怎么删」。
- **Machine Unlearning**：从已训练模型参数中移除特定数据点的「影响」，使模型近似于「从未学过该数据」。
- **数据主体权利（GDPR Art.17）**：被遗忘权/删除权，适用于端侧处理的个人数据。

### 分类
| 维度 | 含义 | 端侧落点 |
| --- | --- | --- |
| 本地留存 retention | 个性化数据/适配层在设备保存 | 滚动窗口、安全区隔离存储 |
| 删除/撤回 erasure | 用户或法规触发移除 | Clear data / 开关即擦除 / 硬件加密擦除 |
| Machine Unlearning | 从模型移除特定数据影响 | 端侧 adapter 删除、近似/精确遗忘 |
| 数据主体权利 Art.17 | GDPR 被遗忘权 | 适用于端侧处理的个人数据 |

### 主流方案
| 方案 | 机制 | 适用 |
| --- | --- | --- |
| 端侧存储隔离 | PCC / Knox Vault 沙箱，数据不出安全区 | 限定留存、防外泄 |
| 安全删除 | 加密擦除 / Ephemeral Data Mode / 重启密钥随机化 | 可证明删除 |
| 差分隐私 | 训练加噪降低单点可推断性 | 联邦/全局模型 |
| 联邦遗忘 FU | 移除某客户端贡献而免全局重训 | 联邦个性化 |
| 可撤销个性化 | 本地 adapter / 记忆独立可删 | 端侧适配层 |

### 2025-2026 进展
- **GDPR**：EDPB 2025 协调执法报告将删除权列为最频繁行使的权利之一；但「AI 模型权重是否构成个人数据」「删除的技术标准」监管尚无定论。学界定「functional neutralization」三要素（不可再现 / 不可推断 / 技术努力比例性）。
- **EU AI Act Art.10**：高风险 AI 系统须做全生命周期数据治理（收集来源、原目的、偏差审查、缺口识别）；特殊类别个人数据须在偏差纠正后或留存期满（以先到者为准）删除。部分条款 2026 年生效，且 2026/1744 Digital Omnibus 有修订 → **生效节点与端侧适用范围待核实**。
- **学术**：Federated Unlearning 综述（IEEE TNNLS 2025）系统梳理 FU 方法与评估指标（MIA、BASR）；发现客户端数据「高记忆、慢衰减」（退出 50 轮后仍残留）。
- **厂商范式**：PCC / Ephemeral Data Mode、Knox Vault、滚动留存窗口成为「本地留存 + 可删」主流实现。

### 代表产品
| 产品 | 端侧留存/删除机制 | 来源 |
| --- | --- | --- |
| Apple Intelligence + PCC | 端侧为主；PCC 无状态计算，响应返回后即不留存、不记日志；重启随机化密钥加密擦除；Apple Intelligence Report 透明日志 | security.apple.com |
| Android Private Compute Core | PCC 沙箱本地推理；使用模式 90 天滚动；Now Playing 手动删；联邦 checkpoint 定期清；Clear data 全删 | androidguias / axis |
| Samsung Personal Data Engine (S25/One UI 7) | 完全端侧不上云；关闭开关即全删；Knox Vault 硬件隔离；云输入交付后立即删 | ZDNET / TechTimes 2025 |
| Google Contextual Suggestions (测试中) | 端侧加密空间处理；本地数据 60 天自动删，可手动提前删 | biggo 2025-12 |
