# 端侧语音大模型（端到端语音 LLM）

> 一句话心智模型：语音不再先转文字再进 LLM，而是原生在语音空间理解与生成，实现全双工、带副语言的对话。

## 广度覆盖
### 定义
端到端语音大模型（Speech LLM / Spoken Language Model）指「语音进、语音出」的单一模型：不依赖 ASR 把语音压成文本、再让文本 LLM 推理、最后 TTS 还原，而是直接在离散语音 token / 连续声学表征空间完成理解、推理与生成。它天然支持全双工（听与说并行）、流式实时、以及副语言（情感、停顿、语气、笑声）建模——这些是级联链路在 ASR 环节就丢弃的信息。与 [[语音交互与端侧 ASR TTS 学习笔记]] 的级联范式形成对照。

### 分类 / 主流方案
| 维度 | 选项 | 说明 |
| --- | --- | --- |
| 范式 | 文本桥接（文本中间表示） | 内部仍解码文本辅助推理，语义稳但副语言易损（如 Mini-Omni、Moshi 配 Inner Monologue） |
| 范式 | 潜表示桥接（连续声学 embedding） | 用音频 encoder 输出喂 LLM，保留音色/韵律，可控性偏弱 |
| 范式 | 离散语音 token 桥接（audio codec） | 主流路线：用神经 codec（Mimi、CosyVoice、RVQ）把语音压成 token 与 LLM 共空间 |
| 能力 | Speech-In（仅语音理解） | Qwen2-Audio、SALMONN、Phi-4-Multimodal |
| 能力 | Speech-Out（仅语音生成） | VALL-E 2、CosyVoice 2 |
| 能力 | Speech-to-Speech（端到端对话） | GPT-4o、Moshi、Mini-Omni、GLM-4-Voice、Step-Audio、Kimi-Audio |
| 部署 | 云端大模型 | GPT-4o / Gemini Live / Step-Audio（100B+ 级） |
| 部署 | 端侧小模型（蒸馏+量化） | Mini-Omni 0.5B、GLM-4-Voice Int4、Qwen2.5-Omni（面向手机/笔记本），呼应 [[端侧大模型推理 学习笔记]] 与 [[端侧模型量化]] |

### 2025-2026 进展
- **2024**：Moshi（Kyutai）首个开源全双工 S2S（~200ms 首包，Inner Monologue）；GPT-4o 首个商业级 S2S（~320ms，含笑声/唱歌）。
- **2025**：路线收敛——中国开源阵营爆发：Qwen2.5-Omni（Thinker–Talker 架构）、GLM-4-Voice-9B、Step-Audio 130B、Kimi-Audio-7B（月之暗面）；端到端 vs 级联之争实质转向「混合架构主导」（复用成熟 encoder + 离散 codec + Flow Matching/轻量卷积解码）。
- **2025-2026**：低延迟成一等约束，多模型把流式输入/输出、打断恢复、长上下文作为核心卖点；评测从 WER 扩展到多轮对话、语音推理、工具调用、自然度、说话人相似度。
- **2026**：端侧小语音模型从「玩具」走向可用——Qwen2.5-Omni 明确面向手机/笔记本部署，GLM-4-Voice 提供 Int4 启动；闭源巨头（GPT-Realtime-2、Gemini 3.x Flash Audio）把实时推理、并行工具调用、实时翻译做成模型卡一等能力。
- 待补充：端到端 vs 级联在生产中的最终取舍（延迟/可控性/幻觉可定位性的权衡）仍在演进，未见定论。
