# 鸿蒙 NEXT 端侧 Agent 与元服务生态 学习笔记

> **一句话心智模型**：鸿蒙 NEXT 不是"又一个手机系统"，而是一套「意图框架 + 系统级智能体小艺 + 元服务轻量入口 + 盘古端侧底座」的端侧 Agent 平台——目标是把"人找应用"压缩成一句自然语言（意图即服务 / 对话即服务）。

本笔记定位：**聚焦「鸿蒙 NEXT 作为端侧 Agent 平台的能力与生态格局」**，刻意区别于库内 [[HarmonyOS 元服务 学习笔记]]（功能层 / 元服务形态罗列），本篇补上「Agent 能力 + 生态迁移」两个维度。相关架构层见 [[端侧意图框架 学习笔记]]，iOS 对照见 [[Apple Intelligence 端侧架构 学习笔记]]。

## 一、广度覆盖（表格）

| 维度 | 代表能力 / 产品 | 2025-2026 进展 | 备注 |
|---|---|---|---|
| **生态迁移里程碑** | HarmonyOS NEXT（纯血鸿蒙） | 2024-10 发布，全栈自研、剥离 AOSP，仅支持 ArkTS + Stage 模型；2025-06 HDC2025 发 HarmonyOS 6；2026-06 HDC2026 发 HarmonyOS 7（开发者 Beta） | 彻底告别安卓兼容过渡期，倒逼全行业原生适配 |
| **应用 / 元服务规模** | 原生应用 + 元服务总量 | 媒体口径差异极大（见待核实）：① 截至 2025-10 应用及元服务破 30 万、Top5000 适配 >95%；② HDC2025 注册开发者破 800 万、超 3 万款原生应用/元服务；③ 2026-08 口径"原生应用破 10 万、手机可获取应用超 40 万、生态设备累计超 13.5 亿台" | 数量级跨度大，统一口径待华为官方核实 |
| **终端覆盖** | 手机 / 平板 / 智慧屏 / 穿戴 / 车机 / PC | 2025-03 首款全面搭载鸿蒙 5 的手机；2025-05 鸿蒙电脑亮相；2026 鸿蒙电脑应用破 1.9 万款；搭载 HarmonyOS 6 终端 6600 万~8000 万台（多口径） | 全场景分布式是鸿蒙相对安卓/iOS 的差异化底座 |
| **系统级智能体** | 小艺（系统调度中枢） | 小艺承担"意图入口"角色，经小艺对话 / 导航条 / Chips / 搜索分发；2025-02 接入 DeepSeek-R1；2026-05 发小艺 Claw（龙虾），Agentic 自演进架构、长期记忆 | 区别于 App 内助手，小艺是跨应用统一调度者 |
| **端侧 Agent 框架** | 鸿蒙智能体框架 HMAF | 2025-06 HDC2025 发布 HMAF +《鸿蒙智能体框架白皮书》，"鸿蒙应用生而智能"；2026 升级 HMAF 2.0：2000+ 鸿蒙智能体、2100+ 系统能力 Skills、200+ 系统级数据、500+ 生态 Skills、复杂任务成功率 >90% | HMAF 全称有歧义：媒体称 Harmony Agent Framework / HarmonyOS Multi-agent Framework，待核实 |
| **智能体开发平台** | 小艺智能体开放平台 | 提供 50+ 鸿蒙系统插件；意图框架升级兼容 MCP；支持 LLM / 工作流 / A2A 多模式；自然语言对话式构建；上架小艺智能体市场多入口分发 | 首批 50+ 先锋智能体（深航飞飞、喜马拉雅小雅、码上飞等） |
| **轻量入口形态** | 元服务 / 万能卡片 / 服务卡片 | 元服务伙伴超 2.4 万家、负一屏月活超 1.9 亿（HDC2026）；发服务分发增长平台 SDG、鸿券通；ASCF 开发框架（高码 + 零代码）；HarmonyOS 6 卡片全面开放 AI 能力接口；互动卡片（闪光桌面） | 免安装、即点即用、多端部署，是 Agent 的轻量触达面 |
| **大模型端侧底座** | 盘古大模型 / 小艺端侧模型 | 小艺基于盘古底座裁剪适配端侧，2025-02 接入 DeepSeek-R1；HDC2026 预告秋季麒麟芯片支持端侧 30B；发 openPangu 2.0（Pro 505B/18B 激活、Flash 92B/6B 激活、512K 上下文）；2026-07-15 小艺 AI 大模型通过手机端侧生成式 AI 服务备案 | 端侧 30B 仍为预告，落地机型/性能待实测 |
| **安全与可信** | 星盾安全架构 / HPIC | HDC2026 发《鸿蒙智能安全白皮书》、HarmonyOS Personal Intelligent Computing（HPIC），强调"本地优先、数据最小化、用户可控"；星盾防诈（AI 变声/换脸检测） | 端侧优先天然契合隐私保护叙事 |
| **平台对照** | vs iOS / Android 端侧 Agent | iOS：Apple Intelligence 端侧 Foundation Models + App Intents（见 [[Apple Intelligence 端侧架构 学习笔记]]）；Android：Gemini Nano via AICore，厂商碎片化；鸿蒙：系统级小艺统一调度 + 意图框架 + 元服务入口，从底层设计 | 鸿蒙无历史代码包袱，AI 内嵌系统底层更快；但生态成熟度仍处追赶 |

## 二、待解问题

- [ ] 待解问题：HMAF 与 Android/iOS 的 Agent 协议（MCP / A2A / App Intents）实际互通深度如何？小艺能否真正跨 App 闭环，还是受限于白名单生态？
- [ ] 待解问题：盘古端侧 30B 模型在麒麟芯片上的真实功耗、内存占用、token 吞吐与离线可用性（华为 JDC 提到的"30B/2B 激活、27GB 占用、<10ms 延迟"是否量产口径？）。
- [ ] 待解问题：元服务 2.4 万伙伴中，真正"Agent 化"（被小艺调度、自然语言触发）的比例是多少？还是多数停留在卡片展示层？
- [ ] 待解问题：鸿蒙 Agent 的"自主执行"权限边界与安全责任如何划分？系统级 Agent 自动调用支付/出行等敏感能力时的用户确认机制。
- [ ] 待解问题：纯血鸿蒙彻底剥离 AOSP 后，长尾应用与海外 App 的覆盖缺口如何补齐？生态"量"与"质"的真实落差（崩溃率 0.1855% 等质量报告指向的体验问题）。
- [ ] 待解问题：小艺 Claw 的付费模式（AI 点数）与端侧模型 OTA 更新机制，是否形成可持续的端侧模型生命周期治理（对比 Apple Foundation Models 随 OS 演进、Google AICore 托管 Gemini Nano）。

## ⚠️ 待核实清单

- ⚠️ **生态规模数字冲突**：应用/元服务总量出现 30 万（2025-10）、"原生应用破 10 万 + 手机可获取超 40 万"（2026-08）、"上架应用与服务超 40 万款"（tecworld）、"原生应用上架突破 580 万款"（CSDN 社区，疑似夸大）多种口径；搭载 HarmonyOS 6 终端有 6600 万 / 7000 万 / 8000 万三种说法。**需以华为官方 HDC 口径或年报为准**。
- ⚠️ **注册开发者数**：HDC2025 称 800 万，HDC2026 口径称超 1100 万，需统一时点。
- ⚠️ **HMAF 全称**：媒体分别写作 Harmony Agent Framework 与 HarmonyOS Multi-agent Framework，官方白皮书为准。
- ⚠️ **端侧 30B 模型**：华为 JDC 社区文称"原生 30B 入端、常驻约 27GB/3GB 运存、<10ms 延迟"；HDC2026 称"秋季麒麟芯片支持端侧 30B"——属预告/社区口径，量产落地机型、真实 benchmark 待第三方实测。
- ⚠️ **小艺端侧生成式 AI 备案**：2026-07-15 网信办新一批手机端侧生成式 AI 服务备案，华为小艺入选（江苏省）——具体备案范围（模型/功能）以备案公告原文为准。
- ⚠️ **智能体数量**：HMAF 2.0 称"2000+ 鸿蒙智能体"，与 HDC2025"首批 50+ 先锋"非同一统计口径（后者为先锋伙伴、前者含全量），避免混用。
- ⚠️ **市场份额"全球第三大手机 OS"**：源自 2026-08 工信部/百度百科表述，按中国市场口径，全球口径需另查。
