低代码 / 无代码 Agent 搭建平台，本质是「把 Agent 的构建从写代码抽象成拖拽/对话的乐高」——让非开发者也能把大模型、知识库与外部工具串成可运行的自动化系统，与 [[AI 编程助手与 Agentic Coding 工具生态 学习笔记]]（开发者编码工具）是两条互不替代的路径。

## 1. 心智模型与分类

一句话：低代码 Agent 平台 = 可视化编排 + 大模型推理 + 工具/知识库接入，目标用户是「想用 AI 但不写代码」的人。按交互形态可分为四类：

| 类型 | 交互方式 | 代表 | 一句话定位 |
|---|---|---|---|
| 对话式 / Bot 工厂 | 自然语言 + 模板 | Coze(扣子)、豆包、Botpress | 5 分钟搭一个能对话的 Bot |
| 工作流自动化 | 节点拖拽 | n8n、Make、Zapier AI | 把一堆 SaaS/系统串起来自动跑 |
| LLM 应用开发平台 | 工作流 + RAG 编排 | Dify、Flowise、FastGPT | 工程化的 AI 应用全生命周期 |
| 企业级 / 云厂中台 | 低代码 + 私有化 | 百度千帆、阿里百炼、腾讯元器、HiAgent | 绑定大模型厂生态 + 合规部署 |

| 产品 | 开源 | 部署形态 | 知识库/RAG | 工具调用 | 适合谁 |
|---|---|---|---|---|---|

| Dify | 开源(Apache-2.0) | 云/自托管 Docker | 强 RAG、知识流水线(2025.9) | Marketplace 插件（数量待核实） | 有技术背景、做 AI 产品 |

## 5. 对 OS PM 的意义

Ethon 作为 Android OS 产品经理，这类平台的价值不在于「学会编码」，而在于：

- **零成本验证需求**：用 Coze/元器 1 小时内搭出「用户反馈分类 Bot」「发布说明生成器」原型，给老板/团队演示，省去排期。
- **打通内部数据**：用 n8n/Dify 把工单、飞书文档、Bug 库串成自动化周报，把重复的跨系统操作交给 Agent。
- **PM 赋能而非替代**：平台把 API 调用、状态管理封装成节点，PM 专注「业务逻辑与提示词」，把工程细节留给平台。
- **选型即判断力**：理解「连接系统(n8n) vs 做 AI 产品(Dify) vs 快速验证(Coze)」的差异，避免在错误平台上浪费时间。

> 与 [[PKM 方法论与 Obsidian 生态 学习笔记]] 结合：可用 Dify/FastGPT 把自己的 Obsidian 笔记库做成可问答的私人知识 Agent。
