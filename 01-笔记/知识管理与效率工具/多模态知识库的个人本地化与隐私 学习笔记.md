> 一句话心智模型：**"本地优先"不是一句隐私口号，而是「架构上根本没有上传通道」——多模态知识库把图像/音频/视频的向量化与检索全部留在设备内，隐私来自没有出网路径，而非厂商的承诺。**

## 🌐 广度覆盖

| 维度 | 要点（点到为止） |
|---|---|
| **定义** | 个人本地化多模态知识库 = 在本地设备（PC / 手机 / 浏览器）上对**文本 + 图像 + 音频 + 视频**做索引、向量化与语义检索，并支持本地 RAG 问答；核心卖点是"数据不出设备"。区别于纯文本本地 RAG（见 [[个人知识库 AI 化与本地 RAG 学习笔记]]），本主题聚焦**多模态**与**隐私架构**。 |
| **分类** | ① 按隐私架构：**真·本地优先**（架构无云端上传路径，如 Local-first 离线应用）vs **"政策承诺"云端**（靠隐私政策保证不上传）；② 按索引模态：OCR+视觉理解（CLIP/BLIP）、音频转写（Whisper/Vosk）、视频关键帧抽取、统一跨模态 embedding 空间；③ 按载体：桌面应用 / Obsidian 插件 / 端侧移动模型。 |
| **主流方案（技术底座）** | ① 跨模态嵌入模型：**EmbeddingGemma 2**（Google DeepMind，740M，Apache 2.0，文/图/音/视频统一空间，8K 上下文，MRL 可截断至 128 维）；② 本地向量库：**ChromaDB / FAISS / Qdrant / LodeDB（嵌入式、private-by-default）/ Rupixel（视觉 RAG，Rust）/ Local multimodal RAG**；③ 隐私优先多模态 RAG 应用：**Glimpse-Edge、SmartRAG、PrivAware-PKM、Hyperlink、LoLA**（均标榜 100% 离线）。 |
| **2025–2026 进展** | ① **2026-10 EmbeddingGemma 2 发布**：端侧多模态嵌入首次小到可装进手机（量化后纯文本 ~191MB、全模态 ~567MB），跨模态检索在端侧跑得轻；② 行业向量库明显向**本地嵌入式、隐私优先**迁移（LodeDB/Rupixel 等增长）；③ Obsidian 本地多模态插件涌现：**Vault Brain、Lumina**（本地 embedding + RAG）；④ 反面教材 **Microsoft Recall** 2025-04 重发布：改为 opt-in + VBS  enclave + Windows Hello + BitLocker。 |
| **代表产品** | 桌面/通用：**Glimpse-Edge**（Electron，100% 离线，ChromaDB）、**SmartRAG**（Ollama + ChromaDB + Whisper + BLIP，2025-12）、**LoLA**（Ollama 桌面，离线 RAG + 视觉）、**Hyperlink**（全设备上 AI agent，Freemium）；Obsidian 插件：**Vault Brain**（Ollama Gemma 4，全库多模态，仅一处 localhost 网络调用）、**Lumina**（ibm-granite 本地 embedding + RAG）、**Smart Connections / Copilot**（可接 Ollama 本地）。 |

## 🧩 关键张力（诚实留白）

- **"本地处理" ≠ "安全"**：Microsoft Recall 全程本地 NPU 处理、不上云，仍因本地攻击面扩大、过滤缺陷、可取证提取而引发隐私风暴——本地化守的是"出网"，守不住"本机被攻破/同机他人访问"。
- **嵌入模型的"检索半边"**：像 EmbeddingGemma 2 只是 RAG 的检索一半，仍需搭配生成模型（Gemma 4 等）才成闭环，且基准多为**厂商自报**，独立复测待补。
- **存储与精度权衡**：MRL 截断省 6 倍空间，但小向量有精度代价；个人百万级向量库的真实取舍未见大规模实测。
