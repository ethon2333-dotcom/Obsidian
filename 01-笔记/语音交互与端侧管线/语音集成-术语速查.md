# 语音集成-术语速查

> 语音工程是一门高度交叉的学科，横跨声学物理、数字信号处理（DSP）、深度学习架构与端侧操作系统调度。
> 本速查表按**系统链路阶段**分类，浓缩各领域最核心、高频的术语、缩写及其在产品架构中的物理含义与决策约束。

---

## 一、语音全链路组件与模块（Pipeline Modules）

| 缩写 | 全称 | 中文名称 | 第一性本质与在系统中的角色 |
| :--- | :--- | :--- | :--- |
| **AFE** | Audio Front-End | 音频前端 | 麦克风硬件采集后的第一道信号调优层，包含 AEC、ANS、AGC，负责提供纯净语音。 |
| **AEC** | Acoustic Echo Cancellation | 回声消除 | **全双工打断的核心**：利用播放端音频作为参考信号，从麦克风混音中自适应滤除扬声器自身发出的声音。 |
| **ANS / Denoise** | Acoustic Noise Suppression | 语音降噪 | 消除环境稳态噪音（空调、风扇）与瞬态突发噪音（键盘声、关门声），提升信噪比（SNR）。 |
| **AGC** | Automatic Gain Control | 自动增益控制 | 无论用户近讲（音量大）还是远场（音量小），自动调节信号振幅至适宜识别的动态范围。 |
| **KWS** | Keyword Spotting | 唤醒词检测 | 常驻在超低功耗 DSP 上的轻量模型（如“小爱同学”、“Hey Siri”），功耗要求 < 5mW。 |
| **VAD** | Voice Activity Detection | 语音活动检测 / 端点检测 | 判断当前音频片段是否含有人声，给出语音起始（Onset）与结束（Offset）时间戳，避免静音空转。 |
| **LID** | Language Identification | 语种识别 | 判断发音所属语言（如中文、英语、粤语、日语），用于向对应的专有 ASR 引擎分发路由。 |
| **ASR / STT** | Automatic Speech Recognition / Speech-to-Text | 语音识别 | 将音频声学特征序列转换为文本 Token 序列。 |
| **Punc** | Punctuation Restoration | 标点恢复 | 原始 ASR 输出通常为无标点文本流，Punc 模型结合语义恢复逗号、句号、问号并进行断句。 |
| **ITN** | Inverse Text Normalization | 逆文本正则化 | 将口语化的发音规整为标准书面格式（如“二零二六年五月” $\to$ “2026年5月”；“百分之五十” $\to$ “50%”）。 |
| **TTS** | Text-to-Speech | 语音合成 | 将文本 Token 转换为可听的自然语音波形。 |

## 二、模型架构与解码核心概念（Model & Decoding）

| 术语 | 全称 / 英文 | 解释与架构取舍 |
| :--- | :--- | :--- |
| **CTC** | Connectionist Temporal Classification | **连接时序分类**。引入特殊占位符 `<blank>`，允许模型在不需要帧级对齐标注的情况下直接学习音频到文本的映射。**特点**：极快、支持非自回归，但缺乏语言模型建模能力（条件独立假设）。 |
| **RNN-T** | Recurrent Neural Network Transducer | **转导器模型**。由 Transcription Network（声学）、Prediction Network（语言）与 Joint Network 组成。天然适合**流式低延迟**识别，当前端侧工业界主流。 |
| **AED** | Attention-based Encoder-Decoder | **基于注意力机制的编解码架构**（如 Whisper）。全局注意力带来极高离线识别精度，但天然不适合原生低延迟流式任务。 |
| **Conformer** | Convolution-augmented Transformer | 结合 CNN 的局部特征捕捉与 Transformer 的长程全局依赖，现代 ASR 最普遍的骨干网络（Backbone）。 |
| **Greedy Search** | 贪心搜索 | 每一步只选概率最高的一个 Token。计算开销最小，延迟最低，但可能陷入局部最优。 |
| **Beam Search** | 集束搜索 | 每一步保留前 $K$ 个最佳候选路径（Beam Size）。精度高于贪心搜索，但内存与算力开销成倍增加。 |
| **Forced Alignment** | 强制对齐 | 已知完整文本和对应音频时，通过声学模型严格反推每个字、词所对应的毫秒级起止时间（对齐）。 |
| **Cache-aware** | 缓存感知流式计算 | 在流式分块输入时，保留上一 Chunk 的历史 Key-Value 缓存，避免跨分块重复计算。 |

## 三、性能与体验度量指标（Metrics）

| 指标 | 全称 | 含义与行业基准 |
| :--- | :--- | :--- |
| **WER** | Word Error Rate (词错误率) | 英文标准评测指标：$$\text{WER} = \frac{S(\text{替换}) + D(\text{删除}) + I(\text{插入})}{N(\text{总词数})}$$ |
| **CER** | Character Error Rate (字错误率) | 中文标准评测指标。由于中文以字为单位且无空格，按单字计算错误率。商用安静场景通常需 $< 3\%$。 |
| **SER** | Sentence Error Rate (句错误率) | 整句中只要有任意一个字错即算错句。衡量用户意图是否完整的直接指标。 |
| **RTF** | Real-Time Factor (实时率) | $$\text{RTF} = \frac{\text{模型推理耗时 (s)}}{\text{音频实际物理时长 (s)}}$$<br>若 RTF = 0.1，表示 10 秒的音频只需 1 秒计算完成。**端侧流式必须保证 RTF < 1.0（通常要求 < 0.3）**，否则音频积压导致雪崩延迟。 |
| **TTFT** | Time-to-First-Token | 首字/首音延迟。从用户停止发声（或发声开始）到端侧屏幕亮出第一个识别文字的时间。 |
| **EOU** | End of Utterance | 句子结束判决延迟。VAD 或语义模型确认用户说完一句话并切断音频流的时间开销（通常 200~400ms）。 |
| **FAR / FRR** | False Alarm / False Rejection | 虚警率（把静音/噪音误判为人声）与漏检率（把真人的微弱声音吞掉）。 |

## 四、信号与特征处理术语（DSP & Features）

| 术语 | 英文 | 概念要点 |
| :--- | :--- | :--- |
| **PCM** | Pulse Code Modulation | 脉冲编码调制，未经压缩的原始数字音频采样序列。 |
| **Frame Size** | 窗长 / 帧长 | 单个计算窗口的时长（典型值 25ms），在 16kHz 下对应 400 个采样点。 |
| **Frame Shift** | 帧移 / 步长 (Hop Size) | 窗口每次向后滑动的时长（典型值 10ms），在 16kHz 下对应 160 个采样点。 |
| **STFT** | Short-Time Fourier Transform | 短时傅里叶变换，将 1D 连续时域波形转换到 2D 频域分布矩阵。 |
| **Fbank** | Mel-Filterbank (Log-Mel) | 经梅尔三角滤波器组加权并取对数的能量谱，模拟人耳听觉特性，80 维为当今标配。 |
| **Clipping** | 削波 / 爆音 | 输入音频振幅超出量化范围（如超过 16-bit 的 32767），波形顶部被削平为方波，导致高次谐波失真，识别率剧降。 |

## 五、交互与系统工程术语（Interaction & System）

| 术语 | 含义与 PM 视角要点 |
| :--- | :--- |
| **Full-Duplex (全双工)** | 允许系统边播报、用户边插话；系统能实时感知并瞬间自我静音，达到真实人类交谈自然度。 |
| **Half-Duplex (半双工)** | 传统“对讲机”模式。系统在说时强制闭麦，用户只能等 Agent 播放完毕才能开麦。 |
| **Barge-in (打断 / 抢话)** | 用户在 Agent 播报过程中随时开口打断的能力。系统需在 150ms 内确认打断并掐断 TTS 链路。 |
| **Hangover (拖尾时间)** | VAD 在判定用户声波降到阈值后，额外向后多录音保留的一小段时间（如 200ms~400ms），防止将断句停顿或句子尾音轻声误切断。 |
| **Chunk / Streaming Window** | 流式 ASR 每次接收的一小段音频缓存（如 160ms 或 200ms）。Chunk 越小首字延迟越低，但局部上下文越少，识别精度越差。 |
