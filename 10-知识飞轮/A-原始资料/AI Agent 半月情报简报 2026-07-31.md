# AI Agent 半月情报简报（2026-07-31）

> 检索窗口≈2026-07-16 ~ 2026-07-31（部分 07-09~07-15 的高信号事件作为「窗口前缘背景」纳入）。原始资料层：保留来源与原始语境，不追求整洁。已据此提炼 B 泛化概念 4 篇、D 输出 1 篇。

## 原始内容

**主线一 · 前沿 Agent 大模型（模型即 Agent 底座）**
- **Claude Opus 5**（Anthropic，7-24）：近 frontier 质量、半价，$5/$25 per M token、1M 上下文；Frontier-Bench v0.1（终端编码 Agent 测试）**43.3%**（Opus 4.8 仅 18.7%、Fable 5 为 33.7%）。新默认模型。
- **Gemini 3.6 Flash / 3.5 Flash-Lite / 3.5 Flash Cyber**（Google，7-21）：3.6 Flash 每任务约少 17% token、计算机使用评测 OSWorld-Verified **83.0%**、计算机使用工具内置于 Gemini API/企业版；3.5 Flash-Lite 350 tok/s、$0.3/$2.5 per M；3.5 Flash Cyber 为安全微调版（仅政府/受信伙伴试点）。Gemini 4 预训练已启动。
- **GPT-5.6 家族 + ChatGPT Work**（OpenAI，7-9，窗口前缘）：Sol/Terra/Luna 三档，Enterprise 上下文 150 万 token；ChatGPT Work 为跨应用执行型 Agent（生成文档/表/报告/网站 + Scheduled Tasks 定时运行）。
- **Cursor Router**（7-22）：请求级模型路由，宣称 frontier 质量下成本降 30~60%。OpenAI 把全双工语音接入 Codex（7-20~26 周）。

**主线二 · 通用 Agent 评测基准（从「刷分」到「可复现」）**
- **AgentCompass**（上海AI实验室，arXiv 2607.13705，7-15 报告）：开源智能体能力评测基础设施，把「模型/工具/环境」三要素解耦，可复现、可扩展。
- **OmniaBench**（arXiv 2607.14989）：通用智能体基准，90 个 L1 / 354 个 L2 域、1431 任务；前沿模型 Overall Pass@1 仅 **Claude-Sonnet-5 58.54 / GPT-5.6-Sol 57.14**，暴露规划/约束保持/自适应纠正短板。
- **AgenticDataBench**（清华+蚂蚁，arXiv 2607.01647，7-10）：数据科学智能体评测，433 个精细技能标签；放宽步数/超时仅 0.6% 任务改善→瓶颈在推理决策而非预算。
- **EdgeBench**（7-22）：面向边缘/端侧 Agent 的 benchmark 与排行榜方法论。
- **A Unified Framework for LLM Agentic Capabilities**（arXiv 2605.27898，5 月）：统一 7 基准/24 域/15 模型/400K rollouts，分离「模型能力 vs 脚手架/环境」效应（方法论背景）。

**主线三 · 企业级 Agent 平台（Agent 成为「组织资产」）**
- **阿里 Agent Native Cloud**（7-18）：AgentRun（一站式 infra）/ AgentTeams（多智能体治理协作）/ AgentLoop（全栈观测）；Infra 层 MicroVM/VM 级强隔离 Sandbox，把 Agent 从「一次性项目」升级为「可控、可复用、可协作、会进化的组织资产」。
- **蚂蚁 Agentar 2.0「AI 超级工厂」**（WAIC）：200 个预置数字专家模板 + 数百即插即用智能体工具；宁波银行复杂问答准确率 68%→91%，能源公司人力成本降 60%。
- **OpenAI Presence**（7-28）：企业级语音/聊天智能体，单任务聚焦（如账单/理赔/IT），75% 来电自动解决，申请制 + 仿真评估前置。
- **WAIC 智能体互联互通协同发展与治理倡议**（7-18，信通院 + 华为/阿里/移动/联通/电信/云天励飞）：统一智能体交互/协同/安全治理共识，破解标准不统一、跨平台难协同。

**主线四 · Agent 身份与硬件级审批（安全范式升级）**
- **YubiKey 5.8**（7-21）：CTAP 2.3 硬件签名，**可对人类审批「具体 Agent 动作」（如改数据库）做密码学确认**，不止登录。
- **Entrust Agentic AI Trust Accelerator**（7-14）：以身份/授权/密码学控制为核心的 co-dev 计划，帮企业把自主 Agent 从试点推到生产。
- **Qoder Security**（7-23）：把安全从「事后扫描」前移到「编码会话中」三层防护，误报降约 80%。
- 同期风险事件：SharePoint CVE-2026-50522 公开利用（数小时盗 machine key）、PyPI `mrmustard` 投毒（import 即窃 SSH/云密钥）；Anthropic 发 Claude Security 插件（多 Agent 审自己代码）。
- 组织 readiness：ManpowerGroup 研究称仅 **3%** 组织领导者「完全准备好」领导 AI 化团队（7-22）。

## 值得保留的点

- **模型竞争维度转移**：从「能力」转向「每任务成本 + Agent 专项基准（编码/计算机使用）」——Opus 5 用半价打 frontier，Gemini 用 Flash 家族碎片化疗程。
- **评测正在「标准化」**：AgentCompass/OmniaBench 等把评测从单点刷分推向可复现、跨基准可比；端侧有 Local Agent Bench、通用有此批，二者互补。
- **企业落地范式成型**：阿里/蚂蚁/OpenAI 一致把 Agent 当「组织资产」经营（沙箱隔离 + 多智能体治理 + 身份/策略 + 仿真评估前置）。
- **安全从「确认 UI」升级到「身份优先 + 硬件级动作审批」**：YubiKey 5.8 把授权锚定到具体动作。
