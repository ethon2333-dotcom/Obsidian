# OS PM 近一月情报简报（2026-07-31）

> 本文件为「原始资料」层：保留来源与原始语境，不追求整洁。检索窗口为近一个月（约 2026-06-30 ~ 2026-07-31），作为 7-30 跨平台简报的增量更新。已据此提炼 → 2 篇新 B 概念（System Orchestrator、Local Agent Bench）+ 5 篇 B 既有概念增补 + 1 篇 D 月报。

## 原始内容

### Apple · iOS 27 / WWDC26（2026-06）
- **System Orchestrator（系统编排者）**：Apple 智能小组实验室明确——"a system orchestrator can take actions from many apps' App Intents across the system — apps don't drive each other directly"。跨 App 动作统一由系统编排者路由，**app 之间不直接互相驱动**；这是**刻意为隐私与安全**的设计：暴露 App Intents 即把动作交给系统级编排者，由其在保持 Apple Intelligence 个人化与私密的前提下协调。
- **前台/后台速率限制**：on-device 模型在**前台无速率限制**（请求事实上无限）；**后台**在系统高负载时施加限流，无固定预算数字。
- **SiriKit 正式弃用**：App Intents 成为 Siri 强制集成面，SiriKit（2016 起）获正式弃用通知，给开发者约 2~3 年迁移窗口；早期伙伴含 Uber / Amazon / YouTube / WhatsApp / AllTrails。
- **新框架族**：Foundation Models framework（原生 Swift API，可切换 Apple / Claude / Gemini 等 LM protocol）、Core AI framework（自带模型上设备）、Evaluations framework（验证 AI 行为）、App Intents Testing framework（无需 UI automation 验证集成）。Platforms State of the Union 阐述 App Intents 如何与 **System Orchestrator + Spotlight 语义索引 + App Toolbox** 协同跨 App 路由。
- **新增实体/意图类型**：`IndexedEntity` + `indexingKey` 已用于 Spotlight 语义索引；WWDC26 扩展了更丰富的实体类型与流式子响应、结构化多轮对话。`ValueRepresentation` / `RelevantEntities` / `EntityCollection` / `SyncableEntity` / `LongRunningIntent` / `ExecutionTargets` 等新型 Schema 类型（细节以官方文档为准，待补）。

### Android · AppFunctions（实验预览 / 2026-05 Gemini 私测）
- **状态**：实验性预览，API 面可能变动；**自 2026 年 5 月起，AppFunctions 与 Gemini 的集成向可信测试人员开放私测**。适用于 **Android 16+（API 36）**。
- **`@AppFunction(isDescribedByKDoc = true)`**：以详尽 KDoc 驱动工具描述；注解处理器在构建时生成 XML Schema，Android OS 索引该文件；Agent 经 `AppFunctionManager` 查询索引、选函数、`isAppFunctionEnabled(packageName, functionId)` 校验后执行。
- **调用方权限**：需 `EXECUTE_APP_FUNCTIONS` 权限，调用方可为智能体 / 应用 / Gemini 等 AI 助手。
- **Agent Skill 生成 Kotlin**：官方发布的 agent skill 分析应用关键工作流，生成 Android 智能系统所需 Kotlin；同时为 AI 代理优化 KDoc，提供测试/调试 ADB 命令；另有**测试智能体**可在模拟智能体环境实验调试。抢先体验计划开放。
- **Google I/O '26 关联**：Android 从 OS 向智能系统转型；发布 **Gemma 4** 与 **Gemini Nano 4（Nano 4）** 开发者预览（经 AICore），ML Kit GenAI 将推 Structured Output API。

### HarmonyOS · HDC2026 ArkAF（2026-06）
- **ArkAF 三层标准体系**：① 意图框架（标准化意图接入+调度，一句话直达基础能力）；② Skills 框架（标准化 Skills 接入+管理，跨应用联动的"线"智能化）；③ 端侧 A2A 框架（多智能体直连协作）。
- **AI 编码辅助**：将意图开发经验封装为意图 Skill，**一句话自动生成意图**，大幅降门槛；同步发布 **DevEco Code 开发智能体 + DevEco CLI**，把鸿蒙开发门槛降到"会说话就能写代码"。
- **小艺规模数据**：DAU **1.8 亿**，日均唤醒 **30 亿次**，日均 Agent 分发量过去一年 **+4.5 倍**；鸿蒙已将 **2100+ 系统能力 Skill 化**开放给小艺，上架 **500+ 伙伴 Skills、2000+ 鸿蒙智能体**。
- **安全**：发布《鸿蒙智能安全白皮书》与鸿蒙智能体安全框架；**HPIC（HarmonyOS 个人智能计算）** 把设备隐私保护延伸到云端，获中国泰尔实验室测评（端侧/云侧隐私框架 + 端云传输隐私 三大检验，达增强级）；小艺 Claw 获信通院首个终端厂商权威安全认证。
- **生态**：已助力 13000+ 应用完成鸿蒙化；抖音/快手实践显示 AI 代码生成率 80%、验证效率 +20%、人效 1.7 倍。（HarmonyOS 7 具体 API level 待官方文档二次确认。）

### Windows · Agent Workspace / Copilot Actions（预览，2025-11 起 Insiders）
- **四大新基元**：① Agent accounts（专属、受限、非交互 Windows 账号，ACL / Intune / MDM / 组策略可治理）；② Agent Workspace（独立轻量桌面会话，运行时隔离，轻于 VM）；③ Scoped file access（默认仅 6 个 known folders：**Documents / Downloads / Desktop / Pictures / Music / Videos**）；④ MCP（On-Device Registry 注册连接器，显式可审计）。
- **默认关闭 + 需 opt-in**：`Settings > System > AI components > Agent tools > Experimental agentic features`，**默认关**、需管理员开启、设备级生效。文件访问同意选项：Allow Always / Ask every time / Never allow。
- **XPIA（跨提示注入）** 被列为头号新型风险：UI/文档中嵌入恶意指令劫持 Agent，导致数据外泄/装马。缓解 = 签名 Agent 二进制 + 防篡改日志 + 管理员开关 + 限定文件夹访问 + 会话隔离。
- **原则**：Non-repudiation（Agent 行为可区分于用户）/ Confidentiality（不低于所消费数据的安全标准）/ Authorization（用户审批所有数据查询与动作）。

### 端侧 LLM 评测（实测，2026-07）
- **FunctionGemma 270M**（Gemma 3 270M 函数调用专版）：Mobile Actions 数据集微调后，**base 58% → 微调 85%**。BFCL 零样本：Simple 61.6 / Multiple 63.5 / Parallel 39 / Parallel-Multiple 29.5 / Live-Simple 36.2 / Live-Multiple 25.7 / Live-Parallel 22.9 / Live-Parallel-Multiple 20.8 / Relevance 61.1 / Irrelevance 73.7。可见**并行/多函数组合场景准确率明显下降**，官方反复强调"必须微调"。
- **S25 Ultra 实测（dynamic_int8, CPU LiteRT XNNPACK 4 线程, ctx 1024）**：Mobile Actions 微调模型 prefill **1718 tok/s**、decode **125.9 tok/s**、TTFT **0.3s**、模型 **288MB**、峰值 RSS **551MB**；Tiny Garden 微调 prefill 1743 / decode 125.7 / TTFT 0.3 / 288MB / 549MB。
- **Local Agent Bench Round 3**（端到端智能体基准，URL 待回填）：**qwen3:1.7b #1（0.960）**；**functiongemma 0.640（435ms）**。

## 值得保留的点

- **编排权上收 OS**：Apple（System Orchestrator）、Windows（Agent Workspace 隔离账号）、HarmonyOS（小艺中枢）一致把"谁来决定跨 App 动作"收归系统层，App 退化为可被编排的能力单元——这是 2026 OS Agent 的核心范式转移。
- **小模型端侧 Planner 已可生产**：FunctionGemma 58%→85% + S25 上 1718 tok/s 证明端侧路由在窄域可达生产级；但并行/多函数仍是短板。
- **安全模型收敛到"隔离 + 签名 + 限定范围 + 用户始终在环"**，XPIA 成为跨平台共认的头号新风险。
