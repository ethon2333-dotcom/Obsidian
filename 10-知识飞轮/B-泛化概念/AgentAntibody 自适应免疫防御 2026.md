# AgentAntibody 自适应免疫防御（2026）

> 库内空白补漏（研究型防御，直接服务于 XPIA 执行安全主题）。此前本库记了 XPIA 的威胁演进（一次性注入 → 文档型蠕虫 → ADI 数据注入，见 [[XPIA 跨提示注入]]）与若干静态防御（隔离 / 确认 / 数据视图隔离 / 来源分级），但**缺「学习型防御」这一支**——AgentAntibody 补上。

## 一句话定义

AgentAntibody（arXiv 2608.04053，2026-08-04 提交）把生物「自适应免疫」思想引入 LLM Agent 的提示注入防御：维护一个**持久化的「抗体库」**，把对用户**安全边界**的不断演化的理解编码进去；运行时识别越界威胁并启动对应免疫响应，并在多次遭遇中持续进化、增强对未来攻击的免疫力。

## 为什么重要

- **解决了静态防御的盲区**：现有防御把每次任务当独立问题，不与历史交互关联。但用户请求往往**欠指定**——只说想要什么结果，没说可接受行为是什么。注入可利用这种模糊性，让 Agent 以「用户会拒绝的方式」完成任务。AgentAntibody 从每次遭遇**学习用户边界**，应用到下次。
- **直击「意图歧义」这一最难场景**：当「有害动作」与「合法动作」都符合给定任务描述时，经典确认/过滤难以区分（两者看都合理）。这是 XPIA 拐点上最棘手的一类（见 [[XPIA 跨提示注入]]）。
- **不止于「拦下」，还保住任务完成**：靠「中止整个任务」来防注入会把合法任务也杀了；AgentAntibody 用「约束受影响的内容与动作」而非全中止，保住实用性。

## 适用边界

- 研究预印本（**未同行评审**），属 LLM Agent 通用安全，非某一 OS 的端侧实现。
- 适用于**多轮、会遭遇重复攻击模式**的 agent 场景（企业助手、长期运行的 agent）；单次一次性任务收益有限。
- 依赖「用户边界可通过对抗样本逐步显现」这一前提；若用户从未表达过边界，初始免疫力来自 baseline，转移能力有限（论文 ablation 实证）。

## 证据与例子（机制 + 基准数字，来源 arXiv 2608.04053）

**核心机制（三个组件，论文 ablation 逐一验证必要性）**
- **Epitope（抗原表位）**：把安全边界编码为**结构化、可迁移**的表示（而非原始文本片段的记忆）。这是跨遭遇「转移」的关键——去掉它，LBB 基准 ASR 从 2.5% → 100%（完全失效），证明「精确原文记忆无法覆盖结构相关攻击」。
- **Maturation（成熟）**：随证据精炼已有抗体（只诱导不精炼则 AgentDyn ASR 11.7% → 18.7%）。
- **Response（响应）**：匹配后**只约束受影响的内容与动作**，不中止任务。去掉它，AgentDojo 的 TSR（任务成功率）从 57.5% → 13.8%、SU-HM 从 72.0% → 24.2%——说明「低 ASR 不等于安全」，全中止毁掉实用性。

**基准结果（3 基准 × 4 backbone LLM，论文 HTML 版数值）**
| 基准 | ASR↓（越低越好） | TSR↑ | BU↑ | SU-HM↑ |
|---|---|---|---|---|
| AgentDojo（AgentAntibody） | 3.8% | 57.5% | 63.3% | 72.0% |
| AgentDyn | 11.7% | 42.8% | 53.3% | 57.7% |
| LBB | 2.5% | 99.0% | 95.0% | 98.2% |

- 横向：在「防有害动作」同时「保住合法任务完成」上，优于现有防御（相对比较，论文未给对每个基线防御的绝对百分比）。
- ⚠️ 诚实标注：以上为**预印本自报数字**，未在 Berkeley AgentBench 等独立榜复现；ASR/TSR/BU/SU-HM 具体定义依论文，跨论文不可直接横向比。

## 可复用启发（给 OS PM / 端侧 Agent 设计）

- **确认 UI 不是终点，用户边界可以「被学会」**：[[Confirmation UI 安全机制]] 是静态、事件级的；AgentAntibody 提示一条互补路径——把「用户拒绝过的动作模式」沉淀为持久策略，下次无需再弹窗。对长期运行的 OS Agent（主动触发意图，见 [[Agentic OS 意图调度内核]]）尤其 relevant，因为主动触发下确认点更难布。
- **「抗体库」本质是「用户安全边界的版本化知识」**：可类比 [[数据溯源分级与单调棘轮]] 的「只升不降」棘轮——边界认知也应单调增强、可审计、可回滚。
- **结构化表示 > 原文记忆**：Epitope 的 ablation 证明「记原文」无法迁移；做端侧意图护栏时，应存**结构化规则**而非**原始对话片段**。
- **安全与实用的权衡要显式化**：AgentAntibody 的 ablation 把「中止任务保安全」的代价量化了（SU-HM 从 72→24），提醒 PM：防注入不能只看攻击成功率，要同时盯任务完成率。

## 反例与边界

- **不是 OS 内建能力**：它是算法层防御，需 agent 框架集成；四平台（Apple/Android/HarmonyOS/Windows）目前**均无公开的「学习型边界防御」**，停留在静态隔离/确认（见 [[XPIA 跨提示注入]] 的「四平台均停留在拐点①」）。
- **冷启动弱**：没有历史遭遇时，baseline 免疫力有限；对全新攻击类别的首轮仍可能中招。
- **隐私代价**：持久化「用户边界库」涉及记忆用户偏好/拒绝模式，需配套数据治理（谁读、存多久、可否清除）——与 [[数据溯源分级与单调棘轮]] 的合规勾稽同源。
