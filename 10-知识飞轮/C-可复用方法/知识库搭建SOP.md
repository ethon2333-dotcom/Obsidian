# 知识库搭建 SOP

## 使用场景

把零散信息转换为可复用知识，并从知识反复产出内容。

## 每次收集

1. 在 `A-原始资料` 新建笔记，使用 [[_模板/原始资料]]。
2. 记录来源、原文重点和你真正想解决的问题。
3. 不在 A 中过度整理；无法判断价值的资料也先保留。

## 每周蒸馏

1. 浏览 A 中本周新增资料。
2. 每个可迁移结论在 B 新建一篇独立概念笔记，使用 [[_模板/概念蒸馏]]。
3. 当一个概念已能稳定指导行动时，在 C 写成步骤化方法，使用 [[_模板/方法SOP]]。
4. 用链接保留 A、B、C 之间的来源关系。

## 每次输出

1. 从 C 选择适用的方法，而不是从空白页开始。
2. 将草稿或成品放入 D，使用 [[_模板/输出复盘]]。
3. 发布或使用后记录反馈、失败原因和新问题。
4. 将新问题或素材回写到 A，形成下一轮输入。

## 完成标准

- A 中每个待处理条目都带有来源与问题。
- B 的概念可脱离原素材单独理解。
- C 的方法可由未来的自己按步骤执行。
- D 的输出带有实际反馈或明确的待验证假设。
