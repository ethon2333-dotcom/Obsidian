# OS PM 2026-07 月报：四平台新增进展

> 输出层（D）。近一个月（约 2026-06-30 ~ 2026-07-31）OS 产品经理前沿情报增量。与 [[AppIntent 跨平台格局总览 2026]]（7-30 版）互补：本篇只讲"这一个月**新发生/新确认**的事"，不重复基础概念。

## 一句话结论

2026 下半年开局，四大 OS 的 Agent 平台不约而同把**"编排权上收系统层 + 端侧小模型可生产化 + 安全默认关闭需 opt-in"** 三条主线坐实。Apple 用 System Orchestrator 把"App 不直接互驱"写进架构；Android AppFunctions 进入 Gemini 私测；HarmonyOS 用 ArkAF 三层 + 小艺 1.8 亿 DAU 把"意图即服务"规模化；Windows 把 Agent Workspace 的隔离/签名/限定文件夹模型讲透。

## 各平台本月新增

### Apple（iOS 27 / WWDC26）
- **System Orchestrator** 登场：跨 App 动作统一由系统编排，App 之间不直接互相驱动（刻意为隐私安全）。→ [[System Orchestrator 系统编排]]
- 前台 on-device 模型**无速率限制**，后台高负载限流、无固定预算。
- SiriKit 正式弃用，App Intents 成强制集成面，约 2~3 年迁移窗口。
- 新框架族：Foundation Models / Core AI / Evaluations / App Intents Testing。
- 详细：[[Apple AppIntents Schema Protocol 2026]]

### Android（AppFunctions）
- 实验预览；**2026-05 起与 Gemini 私测**；Android 16+（API 36）。
- `@AppFunction(isDescribedByKDoc=true)` + 注解处理器生成 XML Schema + `AppFunctionManager.isAppFunctionEnabled` 校验。
- 官方 Agent Skill 自动生成 Kotlin、优化 KDoc、给 ADB 调试命令；另有测试智能体。
- Google I/O '26 同步发 Gemma 4 与 Gemini Nano 4。
- 详细：[[Android AppFunctions 设备侧意图 2026]]

### HarmonyOS（HDC2026 ArkAF）
- **ArkAF 三层**：意图框架 / Skills 框架 / 端侧 A2A 框架。
- AI 编码一句话生成意图；DevEco Code 开发智能体 + DevEco CLI。
- 小艺 DAU **1.8 亿**、日均唤醒 **30 亿**、Agent 分发年增 **4.5 倍**；2100+ 系统能力 Skill 化、500+ 伙伴 Skills、2000+ 鸿蒙智能体。
- 安全：HPIC 个人智能计算（泰尔实验室认证）、小艺 Claw 信通院认证、《鸿蒙智能安全白皮书》。
- 详细：[[HarmonyOS Intents Kit 与 ArkAF 2026]]

### Windows（Agent Workspace / Copilot Actions）
- 四大基元：Agent accounts / Agent Workspace 会话隔离 / Scoped file access（**6 个 known folders**）/ MCP(ODR)。
- **默认关闭**：`Settings > System > AI components > Agent tools > Experimental agentic features`，需管理员 opt-in；文件同意三档（Always / Ask / Never）。
- **XPIA** 列头号新风险；缓解 = 签名 + 防篡改日志 + 限文件夹 + 会话隔离。
- 详细：[[Windows Copilot Actions 与 Agent Workspace 2026]]

## 端侧模型本月实测

- **FunctionGemma 270M**：Mobile Actions 微调 **58%→85%**；BFCL 并行仅 39%（短板在并行/多函数）。S25 Ultra 上 prefill **1718 tok/s**、decode **125.9 tok/s**、TTFT **0.3s**、288MB。→ [[Function Calling 端侧工具调用]]
- **Local Agent Bench Round 3**：qwen3:1.7b **#1（0.960）**、functiongemma **0.640（435ms）**。→ [[Local Agent Bench 端侧智能体基准]]

## OS PM 行动建议

1. **把"编排权上收"当默认架构**：App 只声明能力，系统持编排/审计权（跨四平台一致）。
2. **端侧 Planner 进入选型清单**：窄域路由用 FunctionGemma 级，端到端办事用 qwen3:1.7b 级，评估双轨（BFCL + Local Agent Bench）。
3. **安全默认关闭 + 限定范围**：任何 Agent 能力上线先设 opt-in、限定文件夹、签名与确认。
